# Software Engineer Portfolio

Dark Premium portfolio built with React, TypeScript, Vite and Motion.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalization

Edit `src/data/portfolio.ts` to update your biography, projects, technical skills and social links. Add a public email to enable the email CTA. Project links are intentionally omitted until provided.

## Deploy to GitHub Pages

1. Create a public GitHub repository named `zsckare.github.io` (replace `zsckare` with your actual GitHub username if different).
2. Push the contents of this directory to its `main` branch.
3. In repository **Settings → Pages**, choose **GitHub Actions** as the build/deployment source.
4. The workflow at `.github/workflows/deploy.yml` will build and deploy the site.

For a repository named something other than `username.github.io`, configure `VITE_BASE_PATH` in the workflow build step to `/<repository-name>/`.

For example: `- run: VITE_BASE_PATH=/my-portfolio/ npm run build`.

The workflow uses `npm ci`, so commit the `package-lock.json` generated by `npm install`.


## Professional case studies

Edit `caseStudies` in `src/data/portfolio.ts` to maintain the Geeklab ride-sharing, StaffWizard workforce SaaS, and university operations examples. The descriptions intentionally avoid invented metrics and confidential client assets. Do not upload employer code or screenshots without permission.
